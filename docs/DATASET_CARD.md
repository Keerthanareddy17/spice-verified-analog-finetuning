# Dataset card: Phase 2 (simulator-labeled action choices)

Generated by `scripts/build_dataset.py --config configs/phase2.json` (seed 0). Circuit: two-stage
Miller op-amp, Level-1 models (see DECISIONS.md D1). Every label comes from ngspice, never from a person or a model.

## How it was made
1. **Targets.** 600 random designs (each knob log-uniform in [nominal/3, nominal*3], clipped to bounds),
   kept if the simulation was ok, every device saturated and PM >= 50 deg
   (600 of 1133 candidates kept).
2. **Specs.** Taken from each target's own metrics with slack (gain -U(0,3) dB, UGF x U(0.75,0.95),
   PM -U(0,10) clamped to [45,70], power x U(1.05,1.3)). The target meets its spec, so every spec is achievable.
3. **Start states.** The 7 action knobs of a target are multiplied by 1.3^k (k integer in [-3,3], sum |k| in [2,6],
   no knob allowed to hit a bound). Kept if the sim ran, the spec fails and spec_distance <= 5.
   Of 3600 candidates: 797 already passed the spec,
   0 failed to simulate, 3 were too far.
   Each start is at most 6 inverse moves from its target.
4. **Labeling.** For every state all available actions are simulated; improvement = distance_before - distance_after;
   label = best action (ties: the action whose result has the largest margin beyond the spec, then action-id order; DECISIONS D16). Then the greedy best action is followed for up to
   3 more steps (stopping when the spec is met or nothing improves), labeling each visited state.
5. **Splits** by target (group_id), 80/10/10, seed 0; asserted leak-free.

## Size and cost
- Labeled states: **3679** from 1758 start states / 600 targets.
- Per split (states / episodes / targets): train: 2926 / 1408 / 480, val: 378 / 176 / 60, test: 375 / 174 / 60.
- Unique simulations requested: **55236** (15.0 per labeled state),
  of which 5131 came from the cache. Simulation wall time 250.8 s, whole build 252.6 s.

## Limitations
- Level-1 device models, one fixed load and supply (see DECISIONS.md D1, D2).
- Only the 7 lattice knobs can move; 4 other knobs stay at the target's value.
- Labels are one-step greedy (best immediate improvement), not the best multi-step plan.
- Spec distance is a hand-weighted sum (D7); a different weighting could change the labels.
